# أزهار التقدير — غراس الأخلاق

حديقة تكريم عربية مستقلة. اختر الصف وابحث عن اسم الطالب؛ تتفتح الزهرة عند الضغط وتخرج بطاقة شكر قابلة للحفظ PNG بدقة 1500×1800 والطباعة.

## الملفات
- `index.html`: الواجهة والبطاقة.
- `style.css`: الزهور المتجهية المتحركة والتصميم المتجاوب والطباعة.
- `app.js`: البحث وتفتح الزهور والصوت والتصدير.
- `data.js`: أسماء الحاضرين في تقارير 26 أكتوبر 2026 (الأول 15، الثاني 14، الثالث 15)، وشعار المدرسة الأصلي.
- `flowers-3d.js`: زهور مجسّمة ببتلات منحنية تتفتح تدريجيًا، وإضاءة وصور للبطاقات؛ يرسم محرك واحد الزهور الظاهرة فقط.
- `enhancements.css`: الألوان وإطار شعار المدرسة.
- `vendor/`: Three.js المحلي وترخيص MIT.

لا تعتمد الصفحة على حزم أو خدمات خارجية؛ جميع الموارد محلية. يمكن فتح `index.html` مباشرة. يحفظ المتصفح اختياري الحركة والصوت فقط؛ عداد الزهور المفتوحة يخص جلسة الصفحة الحالية. لا توجد حسابات دخول.

عند عدم توفر WebGL تبقى الزهور المتجهية والتفتح والبطاقات متاحة. التقارير الأصلية وبيانات الغياب وأوقات الحضور لا تُرفق بالموقع.

## الإتاحة
أزرار أصلية قابلة للتشغيل بلوحة المفاتيح، نافذة حوار أصلية تدعم Escape وإرجاع التركيز، دعم تقليل الحركة، ومؤثر صوتي اختياري مكتوم افتراضيًا.
