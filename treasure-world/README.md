# عالم الكنوز — النسخة المجسّمة

منصة تكريم للحاضرين فقط، تضم 41 صندوقًا شخصيًا وثلاثة عوالم مضيئة. بطاقة الشكر تحمل الاسم الثلاثي وتوقيع عبد الرحمن نصر الله، مع تغيير القالب والحفظ والطباعة.

الصندوق نموذج GLB متحرك من Kenney Pirate Kit 2.1 بترخيص CC0: https://kenney.nl/assets/pirate-kit . يحتوي حركة فتح الغطاء؛ أُضيفت خامة خشب ومواد ذهبية وإضاءة ودوران بالسحب. يعمل عبر Three.js 0.128.0 وGLTFLoader، بترخيص MIT المحفوظ داخل vendor. النموذج والخامات والمحرك محفوظة محليًا.

الشهادة ذات إطار ذهبي، ختم متحرك، لمعان، دخول ثلاثي الأبعاد، ميل بالمؤشر، وجزيئات احتفال. يمكن إيقاف الحركة وكتم المؤثرات. لا توجد قراءة أسماء أو خدمات مدفوعة. إذا تعذر WebGL، يعمل فتح الصندوق بالتأثير البديل.
