# رسالة من نجمتك

مشروع مستقل عن منصة البالونات، وله عنوان ومسار خاصان. اختر الصف والاسم، وافتح رسالة النجمة لتسمع ترحيبًا بالاسم الأول وكلمة شكر عربية، ثم تظهر بطاقة باسم الطالب وتوقيع عبد الرحمن نصر وكلمة تقدير للأسرة.

يمكن إعادة الاستماع، وكتم الصوت، وإيقاف الحركة، وتنزيل البطاقة صورة PNG، أو طباعتها. يُنطق الاسم المركب كاملًا مثل عبد العزيز وعبدالله.

الأصوات ملفات MP3 مُولَّدة بصوت عربي اصطناعي، وليست تسجيلًا بصوت المعلم الحقيقي. تُشغَّل من ملفات المشروع؛ لا تُرسل أسماء الزوار إلى خدمات صوتية عند الاستماع. عند تعذر تحميل ملف يستخدم البرنامج صوتًا عربيًا محليًا إن كان متوفرًا، ويعرض إشعارًا إذا لم يتوفر.

افتح index.html أو الرابط المنشور، واحتفظ بمجلد audio بجواره. اختيار الاسم ليس تحققًا من الهوية. ملفات المشروع القديم لم تُعدّل.
