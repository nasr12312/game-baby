# سماء الشكر — غراس الأخلاق

منصة تفاعلية للطلاب: اختر صفك، وابحث عن اسمك، واضغط البالون لفتح بطاقة شكر بتوقيع عبد الرحمن نصر.

يمكن حفظ البطاقة صورة PNG أو طباعتها، وفتحها مجددًا. لا توجد لوحة تحكم أو حسابات دخول. اختيار الصف لا يتحقق من هوية المستخدم.

افتح index.html في متصفح حديث. يعمل الملف دون تثبيت، ويدعم الهواتف والشاشات الكبيرة وتقليل الحركة والتنقل بلوحة المفاتيح. اضغط Esc لإغلاق البطاقة.
