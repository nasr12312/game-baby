# أهل القرآن — منصة التكريم

لوحة عربية متحركة للشكر في حصص القرآن، تعمل من ملف واحد دون إنترنت أو تثبيت.

افتح index.html، ثم «لوحة التحكم». أضف الأسماء كل اسم في سطر، وحدد الصف والشعبة وسبب التكريم. اختر تكريمًا فرديًا أو لوحة شرف أو عرضًا متتابعًا، واضغط «تشغيل». «عرض كامل» مناسب لشاشة الصف.

يمكن تعديل الأسماء، تحديد المشاركين، البحث والتصفية، تغيير قالب الألوان وحجم الاسم والمدة وعبارات الشكر، وتنزيل البيانات واستيرادها وطباعة اللوحة.

البيانات محفوظة محليًا في المتصفح، ولا تُرسل إلى خادم. المستودع لا يحتوي على أسماء حقيقية. تغيير الجهاز أو المتصفح لا ينقل الأسماء؛ استخدم نسخة البيانات. يتوقف العرض عند فتح لوحة التحكم أو الانتقال لتبويب آخر. يدعم تقليل الحركة، ولوحة المفاتيح: سهم يسار للتالي، سهم يمين للسابق، مسافة للتشغيل، وEsc للخروج.

لوحة الشرف تعرض تسعة أسماء في الصفحة. اضغط أي بطاقة لتكريم صاحبها فرديًا. لا توجد موسيقى أو أصوات.
