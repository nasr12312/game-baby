# سماء الشكر — غراس الأخلاق

اختر صفك من الصفوف الثلاثة، وابحث عن اسمك، واضغط البالون لفتح شهادة شكر بتوقيع عبد الرحمن نصر.

يمكن تنزيل الشهادة صورة PNG أو طباعتها. يظهر شعار المدرسة في ترويسة الشهادة. لا توجد لوحة تحكم أو حسابات دخول.

الحركة الكاملة مفعّلة مع زر لإيقافها وإعادتها، وزر مستقل لكتم الأصوات. تعمل الأصوات بعد أول تفاعل مع الصفحة. يُحفظ اختيار الحركة والصوت في المتصفح.

افتح index.html في متصفح حديث. يدعم الهاتف وشاشة الصف ولوحة المفاتيح. اضغط Esc لإغلاق الشهادة.
